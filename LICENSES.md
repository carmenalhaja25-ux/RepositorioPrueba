Tarea 1: El Escudo Legal

1. Apache Guacamole se distribuye bajo la licencia Apache v2.0. Es una licencia de software libre permisova que permite el uso de modificación y distribución del software.
https://guacamole.apache.org/

2. Open SSH se distribuye bajo la licencia BSD / MIT (estilo permisivo). OpenSSH no tiene una licencia única, sino una combinación de licencias de código abierto similares  BSD y MIT debido a sus diversos componentes.
https://www.openssh.org/

3. PostgreSQL se distribuye bajo la licencia PostgreSQL. Es una licencia permisiva de tipo open source similar a BSD o MIT.
https://www.postgresql.org/
